# source-command-worktree-finish

Use this skill when the user asks to run the migrated source command `worktree-finish`.

## Command Template

# Finish Worktrees - Create PRs

Finalize work in worktrees by creating Pull Requests to merge into dev.

## Step 1: List All Worktrees

```bash
git worktree list
```

Show all worktrees and their branches.

## Step 2: Ask Which to Finish

Use AskUserQuestion:

**Question: Select Worktrees**
- Header: "Finish"
- Ask: "Which worktrees do you want to create PRs for?"
- Options:
  - "Current worktree only"
  - "All worktrees (excluding dev/main)"
  - "Let me choose specific ones"

If "Let me choose", list the worktree branches and let user multi-select.

## Step 3: For Each Selected Worktree

Navigate to each worktree and:

### 3a. Check for Uncommitted Changes

```bash
cd <worktree-path>
git status --porcelain
```

If there are uncommitted changes, ask user:
- "Commit changes first?" → Run commit flow
- "Skip this worktree?" → Continue to next
- "Stash changes?" → git stash

### 3b. Push Branch

```bash
git push -u origin <branch-name>
```

### 3c. Create PR

```bash
gh pr create --base dev --head <branch-name> --title "<auto-generated-title>" --body "$(cat <<'EOF'
## Summary
<Generate from commit messages on branch>

## Changes
<List of commits since branching from dev>

---
🤖 Generated with [Codex](https://Codex.com/Codex)
EOF
)"
```

If PR already exists, show the URL instead.

## Step 4: Ask About Cleanup

Use AskUserQuestion:

**Question: Cleanup**
- Header: "Cleanup"
- Ask: "Do you want to remove the finished worktrees?"
- Options:
  - "Yes, remove worktrees (keep branches)"
  - "No, keep worktrees for now"

If yes:
```bash
git worktree remove <worktree-path>
```

## Step 5: Summary

Report:
- ✅ PRs created (with URLs)
- ✅ Worktrees cleaned up (if applicable)
- Remaining worktrees (if any)

**Remind user:**
- PRs target the `dev` branch
- Review and merge PRs in GitHub
- Use `/worktree-list` to see remaining worktrees
