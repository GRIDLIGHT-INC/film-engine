4 · Layout persistence

  • Auto-place from the shot list: one group per sequence, shots in a column, sequence to the right, versions right of their parent, sound nodes under the sequence.
  • Store positions like film_flow_nodes.position_x/y — new table production_node_layout (project_id, node_key, x, y, pinned).
  • Dragging sets pinned=1. "Tidy layout" re-places only unpinned nodes.
  • node_key = shot:<id>, seq:<id>, sound:<id>, ver:<id>, link:<seq>:start|end.

5 · Wiring rules

  • Shot image → Sequence slot: adds the shot (a shot belongs to one sequence; wiring it elsewhere asks to move it).
  • Shot/Sequence scene → SFX/Ambient/Music: that node's "scene details" come from it.
  • Sequence end frame → another sequence's start slot: creates a Linked frame node, never membership.
  • Generators → version nodes are created by the server, never drawn by hand.
  • Type-check on drop using port colours; show .fedge-ghost while dragging.

6 · Playback

  • Running order from lib/running-order.js / routes/timeline.js.
  • Per shot: selected video version → else selected image held for the card's duration_seconds → else a slate.
  • A sequence with a selected video version plays once across its members' span.
  • Audio lanes play the selected sound versions under their parent's span.
  • Clicking a tile selects its node and pans to it; the playhead follows selection.

7 · Interactions

  • Click node → drawer. Click canvas / Esc / × → close.
  • Drag from the side-panel outline or palette → new node at the drop point.
  • Right-click node or group → Run, Duplicate, Remove from graph.
  • "Run pending" = every node whose selected output is missing; show the free plan / estimate before spending (same rule as the existing run plan).
  • Progress streams onto the node (SSE routes already exist for storyboard and video).
  • Lock board disables every action that replaces a frame.

9 · Done when

  • Every capability from the 8 old pages is reachable (see "Where today's 8 pages go").
  • A shot can be generated, uploaded, regenerated and have any version selected from its drawer.
  • A sequence with a continuous join generates one clip per leg; a cut generates nothing.
  • A linked frame resolves to the selected version and flags staleness when it changes.
  • SFX/Music preview is free and shows the exact text sent.
  • Playback plays the selected versions in order with stills and slates filling gaps.
  • Positions survive reload; Tidy layout leaves pinned nodes alone.
  • Tests: nav-reorg, ios byte-identity, and new tests for layout, linked frames and playback order.
